# KKU HR Exp

ระบบบันทึกงานและแจ้งปัญหาสำหรับ **นักวิชาการโสตทัศนศึกษา มหาวิทยาลัยขอนแก่น**
ใช้งานบนมือถือเป็นหลัก — บันทึกเวลาอัตโนมัติ · แนบรูป/ไฟล์ได้ · Admin Export CSV/Excel

## สถาปัตยกรรม

```
index.html (GitHub Pages)  →  Code.gs (Google Apps Script)  →  Google Sheets + Drive
```

| ส่วน | เทคโนโลยี | ที่อยู่ |
|---|---|---|
| Frontend | HTML + Tailwind CSS + Google Identity Services | `index.html` |
| Backend API | Google Apps Script | `apps-script/Code.gs` |
| Database | Google Sheets (`Users`, `Work_Logs`, `Issues`) | บัญชี @kku.ac.th |
| Storage | Google Drive (โฟลเดอร์ `KKU HR Exp - Uploads`) | บัญชี @kku.ac.th |

## ฟีเจอร์ (สรุปทุก Phase)

- **Login** ด้วย Google เฉพาะอีเมล `@kku.ac.th` + ชื่อ-นามสกุลจริง
- **บันทึกงาน / แจ้งปัญหา** พร้อม Auto Timestamp + แนบรูป/ไฟล์ (ย่อรูปอัตโนมัติ เก็บขึ้น Drive)
- **AI (Gemini)** แยกประเภทงาน/ปัญหา และตรวจความเกี่ยวข้องก่อนบันทึก
- **กันการทุจริต (Phase 5)** — กันสแปม · กันเนื้อหาซ้ำ · กันเนื้อหาไม่เกี่ยวกับงาน
- **XP / Level / ยศ** ตามเกณฑ์ที่แอดมินตั้งได้ + คลังองค์ความรู้ (Knowledge Base) + Like
- **แดชบอร์ด (Phase 5.2)** — สถิติส่วนตัว, กราฟ XP 6 เดือน, สัดส่วนกิจกรรม, จัดอันดับสมาชิก
- **RPG (Phase 6.0)** — ธีมไซเบอร์ · แอนิเมชัน Level Up + XP ลอย + เสียง · **สตรีค**วันติดต่อกันพร้อมโบนัส · การ์ดตัวละครในโปรไฟล์
- **Achievements (Phase 6.1)** — เหรียญตรา/ความสำเร็จ ปลดล็อกอัตโนมัติ + XP รางวัล + แอนิเมชันฉลอง
- **ประวัติไฟล์/ลิงก์ (Phase 6.1.1)** — แยกรูป (thumbnail) กับไฟล์อื่น (PDF/เอกสาร) · ปุ่ม 📋 คัดลอกลิงก์ทุกไฟล์/ลิงก์ · เปิดดูจากมือถือได้
- **จัดการผู้ใช้ (Phase 6.6)** — แผงแอดมิน: รายชื่อสมาชิก · อีเมล · XP · ลำดับ ranking · ค้นหา/เรียง · เจาะดูรายละเอียดการบันทึกทั้งหมด (ไฟล์/ลิงก์/สถานะยกเลิก)
- **ตีกลับ/แก้ไข + รอส่ง (Phase 6.7)** — แอดมินแก้ไขหรือ "ตีกลับ" รายการได้ (หัก XP คืน + เหตุผล) · ผู้ใช้มีแท็บ **📤 รอส่ง** แก้ไขแล้วส่งใหม่รับ XP คืน
- **แต้ม XP ต่อกิจกรรม (Phase 6.8)** — แอดมินกำหนดได้เองว่าบันทึกงาน/แจ้งปัญหา/เสนอวิธีแก้/ยืนยันสำเร็จ/Like ได้กี่แต้ม (มีผลกับการบันทึกครั้งถัดไป)
- **Smart Work Capture (Phase 2 / build 6.18)** — ขั้นตอนบันทึกงานง่ายขึ้น: คำแนะนำงาน vs ปัญหา · สถานะการส่ง 6 แบบ (พร้อม/กำลังบันทึก/สำเร็จ/ไม่สำเร็จ/รอผล/ออฟไลน์) · กันกดซ้ำ · ไฟล์แนบมีสถานะประมวลผล · **ไม่ล้างข้อมูลจนยืนยันสำเร็จจากเซิร์ฟเวอร์** · ย้อนหลังแสดงวันที่ชัดเจน
- **แก้ไข/ลบรายการของตัวเอง (Phase 6.19)** — จากหน้าประวัติ ผู้ใช้ **แก้ไขข้อความ** (XP คงเดิม) และ **ลบงาน/ปัญหาที่ตัวเองส่ง** ได้ · ลบแล้ว **หัก XP ที่เคยได้คืน** (ซอฟต์ดีลีต — แอดมินกู้คืนได้ + มี audit log)
- **เมนูใหม่ + Export + ความเป็นส่วนตัว (Phase 6.20)** — หน้าแรก = **บันทึก** · บอร์ด→**บอร์ดปัญหา** · ย้าย **ประวัติ** ขึ้นแถบล่าง · **แดชบอร์ด**+ค้นหา/รอส่ง/โปรไฟล์/แอดมิน อยู่ใน **⋯ เพิ่มเติม** · **แดชบอร์ดมีปุ่ม Export ข้อมูลของตัวเอง** เลือกช่วงวันที่ได้ (CSV/Excel) · **ซ่อนชื่อ/อีเมลผู้โพสต์ปัญหา+ผู้เสนอวิธีแก้ ในบอร์ดปัญหาและคลังความรู้** (แสดงเป็น "เพื่อนร่วมงาน" — เห็นตัวจริงเฉพาะแอดมิน)
- **จัดกลุ่ม "ปัญหา + ข้อเสนอแนะ" ชัดเจน (Phase 6.21)** — บอร์ดปัญหา/คลังความรู้/ผลค้นหา แสดง **ปัญหาและข้อเสนอแนะใน card เดียวกัน** โดยมีหัวข้อกำกับ **"💡 ข้อเสนอแนะสำหรับปัญหานี้"** (พร้อมจำนวน) แยกจากตัวปัญหาให้เห็นชัดว่าเป็นของปัญหาใด
- **เปิด/ปิดการมองเห็นอันดับ (Phase 6.22)** — แอดมินสลับ **เปิด/ปิด** การแสดง **"🏆 ผู้ทำคะแนนสูงสุด"** และ **"👥 อันดับสมาชิกทั้งหมด"** ให้ผู้ใช้ทั่วไปเห็นได้ (แอดมินเห็นเสมอ) · แบ็กเอนด์ไม่ส่งข้อมูลอันดับให้ผู้ใช้ทั่วไปเมื่อปิด
- **ตรวจรายละเอียดครบ + แก้/ลบได้ทุกส่วน (Phase 6.23)** — แอดมินในแผง **🧾 รายการส่งข้อมูล** กดขยายดู **ไฟล์แนบ(รูป)/ลิงก์/ข้อเสนอแนะทุกข้อ** ของแต่ละรายการ · **แก้ข้อความ**รายการและข้อเสนอแนะ · **ลบข้อเสนอแนะ/ไฟล์แนบ/ลิงก์** (ลบข้อเสนอแนะหัก XP ผู้เสนอคืน · ไฟล์ใน Drive ไม่ถูกลบ)
- **ประเมินการบริการ + กันสแปม (Phase 6.23.1–6.26)** — ป้ายแต้ม XP ทุกปุ่มดึงค่าจริงจากตั้งค่าแอดมิน · **ประเมินการบริการหน้างานผ่าน QR** (`evaluate.html`, XP = จำนวนดาว) · แอดมินดู/ยกเลิกผลประเมิน (หัก XP คืน) · แท็บ **รายงานการประเมิน** (สรุปคะแนนเฉลี่ยต่อเจ้าหน้าที่ + โปรไฟล์เจ้าหน้าที่) · กู้คืนผลที่ถูกยกเลิก · **กันสแปมฟอร์มสาธารณะหลายชั้น** (honeypot/คำหยาบ/ลิงก์/เนื้อหาซ้ำ)
- **ภารกิจ + เหรียญ + ร้านค้า (Phase 3 / build 6.27)** — แอดมินสร้าง **🎯 ภารกิจ** (กำหนดจำนวนคน/ระดับขั้นต่ำ/ภารกิจก่อนหน้า/รหัสลับ+ช่วงเวลา/จุดเช็คอิน+รัศมี (ปักหมุดบนแผนที่)/ทำซ้ำได้/เหรียญรางวัล) · ผู้ใช้ **เข้าร่วม–เช็คอิน–กรอกรหัส** รับเหรียญ (🪙) และดู **ประวัติการเข้าร่วม** · **🎁 ร้านค้า** แลกของรางวัลด้วยเหรียญ (ราคา/สต็อก/จำกัดต่อคน/ช่วงระดับ/ภารกิจที่ต้องผ่าน) · แอดมินจัดการรายการแลก (รอรับ/รับแล้ว/ยกเลิก–คืนเหรียญ)
- **แอดมิน**: ตรวจ/ยกเลิกรายการ (หัก XP คืน + audit), ดูข้อมูลรายบุคคล (drill-down), ประกาศ, จัดการสิทธิ์, จัดการภารกิจ/ร้านค้า, Export CSV/Excel
